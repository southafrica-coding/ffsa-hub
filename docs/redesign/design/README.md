# The design file

`FFSA Hub Redesign.dc.html` — open it in a browser. **91 frames, 0a → 31e.**
Everything beside it (`brand/`, `icons/`, `support.js`, `image-slot.js`) is what
it needs to render standalone; all references resolve.

Cite frame ids from this file in every report. Written recipes in the parent
folder are a summary of it, not a substitute — working from the recipes alone is
how earlier sessions missed whole screens.

Deliberately NOT copied from the original bundle: `uploads/` (~40MB of brand-deck
PDF and screenshots) and `brand/ffx-graphic.png` (3.3MB). Nothing in the design
file references them, and the repo does not need the weight. They remain in the
original download if ever wanted.

Note: the canvas is ~88,000px tall, which defeats some screenshot tools. Scroll
to a frame by id instead.
